How to use

Step 1 — Download the template

Choose who you're importing and which columns you need, then click Download Template. The file includes dropdown validation lists built from live data in this database.

Step 2 — Fill it in

Open the Excel file and complete one row per user. Use the dropdown arrows in each cell — values outside the list will be flagged as errors on upload.

Step 3 — Upload & import

Drag the completed file into the upload area. Review the preview, then click Import. A results file downloads automatically when complete — it includes the temporary password for each user.

Passwords

If you leave the Temporary Password column blank (or don't include it), a secure password is auto-generated. MyGeotab will prompt the user to change it on first login.
